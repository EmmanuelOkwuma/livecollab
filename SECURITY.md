# Security

## Reporting a vulnerability

Please report security problems in LiveCollab privately, by email to emmanuelokwuma111@gmail.com. Don't open a public issue for them.

Include what you found, the steps to reproduce it, and the LiveCollab version (LiveCollab > About LiveCollab in the app). You'll get a reply to confirm your report was received.

## Scope

This covers the LiveCollab desktop app in this repository, the LiveCollab server it connects to, and livecollab.dev.

Problems in Visual Studio Code or Code - OSS that aren't specific to LiveCollab should go to Microsoft: see https://github.com/microsoft/vscode/blob/main/SECURITY.md.
